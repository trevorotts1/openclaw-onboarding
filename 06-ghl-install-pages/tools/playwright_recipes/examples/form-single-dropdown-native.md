# Native Single Dropdown creation and editing

Use `forms.configure` with `widget_fields` and kind `single_dropdown`. An explicit
`index: null` creates one new owned field through Quick Add; an existing one-based
canvas index requires its complete previous field inventory. Supply every captured
General/Advanced property, Required flag, ordered option labels and explicit
calculation values or absence. Hidden, Other, style and columns are not exposed
by this measured Single Dropdown panel and are refused.

The shared adapter checks the generated default identity and three default
choices before authoring a new field, preserves all unrelated field snapshots
and native query identities, saves once and independently reopens. Existing
custom-field name/canonical contact Unique Key are immutable. Completed public
CLI replay rereads saved native fields and siblings before reporting completion.

Native creation closes the Contact option-array creation gap without inventing
an undocumented API request. The existing API-owned Dropdown placement path is
unchanged. The example is synthetic; replace identity and complete previous
field inventories with current location/form evidence.
