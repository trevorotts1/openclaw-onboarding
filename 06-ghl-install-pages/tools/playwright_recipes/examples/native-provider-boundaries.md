# Native proof across provider transports

Every editor operation registered in `intake.FIELDS` requires its maintained
compiled job and native writer journal. This classification is the default for
future registered editor schemas, including malformed requests; it is not a
list of selected question or field keys. Compilation and normal job validation
must succeed before a native request becomes script-ready. Unknown actions
remain rejected by the runner.

Canonical `route.API_OPERATIONS` keep their API adapters and capability checks.
The explicit `meetings.integrate` mode `permanent_calendar_link` also keeps its
API contract. Course product media, outline updates and lesson quizzes therefore
retain their existing API paths. A generic capability for a broad editor
operation does not prove that its concrete native configuration was performed.
Bound 401/403 refusals remain terminal.

The measured lane order remains Playwright, current OpenClaw extension, managed
Agent Browser and enabled computer use. For an editor job on a fallback browser
lane, the host must supply its already managed, tenant-bound compatible `page`
object. The host invokes the same `run_on_page(page, job, evidence_root)` and
maintained leaf as Playwright. It does not invoke a generic registered provider
callback and accept that callback's completion status. No compatible Page means
`CAPTURED_SCRIPT_ROUTE_REQUIRED`, with no provider write or completion journal.
Portal operations also retain their opaque same-session context and scoped
authorization requirements.

The Page is a live host-owned driver object with the methods required by the
maintained leaf, not caller-authored JSON or a flag claiming that a browser is
connected. This interface does not manufacture a bridge from extension tools
to Python. The host must already have a real compatible driver. Its native
actions still record intent before mutation, preserve uncertain writes and
validate completed receipts before replay; changing browser lanes does not
authorize another create or Save.

The regression matrix compiles 69 valid examples covering all 56 current editor
actions and refuses generic status-only API/browser completions. Positive Page
transport tests exercise the real host and runner, exact leaf receipt checks,
intent ordering, aged completed replay and corrupted identity refusal. They
establish the interface contract, not live extension execution or native
functional, submission, payment or notification acceptance.
