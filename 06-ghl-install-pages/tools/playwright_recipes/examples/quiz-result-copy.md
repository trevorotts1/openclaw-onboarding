# Quiz result editing

## Existing Individual category media

See `quiz-individual-category-media.json` for a complete `quizzes.configure` request. It targets an existing Individual category section and exact category, with media enabled. Supply its current type, URL and placement; when switching type, also supply the current URL and placement of the target type. Supported placements are Left center, Right center, Top, Bottom, Left fixed and Right fixed. The writer checks protected content and other fields, saves, and independently reopens. It does not add sections or categories; live runtime acceptance remains unverified.
