# Skill 71 Operator / Agent Instructions

## Trigger

Use Skill 71 when a client asks for a focused BlackCEO landing-page-type experience: landing page, opt-in/squeeze page, registration/event page, challenge page, booking page, lead-generation page, or comparable single-page conversion page.

Do not use Skill 71 when the request clearly names the specialized multi-step/direct-response/cinematic families owned by Skills 49, 56, or 62. See `MASTERDOC.md`.

## Execution

1. Read `SKILL.md` and `references/authority-map.md`.
2. Resolve Standard vs Long-Form and any genuinely missing page/action facts.
3. Follow the Production/QC SOP stage order.
4. Load only the stage-specific reference needed now.
5. For image work, load Image Intelligence v5; choose one page-level Creative Direction family/style or Secret-Sauce-only.
6. Delegate provider execution to Skill 66/63 rather than hand-rolling image calls.
7. Delegate GHL delivery to Skill 6.
8. Produce preview/review artifacts and publish only under current authorization rules.

## Important routing distinction

"Landing page" by itself belongs here.
"Signature Funnel" / 3-5-7 / upsell/downsell belongs to Skill 49.
"Direct-response sales page" / VSL / order bump / high-ticket belongs to Skill 56.
"Cinematic/scroll/animated website" belongs to Skill 62.

## Maintenance check

`bash verify.sh` is for installation/update verification. It is not part of every normal landing-page job.
