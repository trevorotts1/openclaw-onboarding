Drama Studio — pairing and admin

Mint a pairing code, make a personal link, check a key, set the option, see the cutoff. Everything here talks to the studio service; nothing here holds a credential of its own.

1. Pair a client’s computer

Mint a code for this client. It is single use, good for 15 minutes, and it burns the moment their computer uses it.

The studio’s id for this client, like c-9f2… (the letter c, a dash, 32 characters). Never a name.

Sent in the request body only. It is never stored in this page, never put in a URL and never shown back.

Pairing code — read it out, or let their computer scan the square.

On their computer, run studio.py pair and enter that code, or scan the square above.

2. Check a key, or cut one off

Paste a key to see whether the studio still accepts it, and whose record it opens. The key is sent in the x-ds-key header, never in the address bar.

The value is never displayed again and never written down; this page can only hold it while the tab stays open.

Uses the admin key from section 1. It marks every key of that client and that kind revoked, so a leaked key stops working at its next check-in. It never asks for, shows or returns a key value.

3. Set the option

The option is per client. Option 3 starts their crew automatically and needs a recorded approval, by name, for that one client.

Option for this client

The name the approval is recorded against. Option 3 is refused without it — by this page and again by the service.

4. Cutoff

The time of day new orders stop starting for a client. Version 0 has no cutoff route on the studio service: this page computes and shows the cutoff, and refuses, by name, to claim it was saved.

Local to the client’s timezone below.

An IANA name, like America/New_York.

5. Make a personal link

The link a client opens on their phone, as a QR they can scan. Making a new one stops the old link working at once, so only the link you hand over works. It uses the admin key from section 1.

The studio’s id for this client, like c-9f2… (the letter c, a dash, 32 characters). Never a name.

Personal link — scan the square, or copy what is under it.

Send it to this client. It keeps working until you make another one; then the old one stops at once.
