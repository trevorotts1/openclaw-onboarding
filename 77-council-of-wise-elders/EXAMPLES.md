# Council of Wise Elders: Examples

All examples are phrasing and shape references. The decision content in
the last example is synthetic fixture material, unmistakably labeled,
and is not a real client decision, not a real verdict, and not evidence
that a council has run.

## Convening the council

Client: "Ask my Council of Wise Elders: should we open a second
location this year, or put the same money into the online store?"

Agent behavior: resolve the client and any existing session for this
decision, gather permitted context (cash position, lease constraints,
current store performance), show the prepared brief with unknowns
marked, confirm the selected route and run grant, then convene.

## A named-seat consult

Client: "Ask the Tiffany Aliche seat whether we can afford a second
van."

Agent behavior: a single-seat consult, labeled with the seat's exact
profile label, answering the affordability question with conditions and
the figures it still needs. It is presented as one perspective, never
as a council verdict.

## Existing-session controls

Client: "What did they decide?"
Agent behavior: a read. Return the stored verdict for the resolved
session. No new inference, no new session.

Client: "Stop that council."
Agent behavior: resolve the existing running session and cancel it.
Never create a task or session titled Stop that council.

Client: "Explain Russell's objection."
Agent behavior: retrieve the recorded objection from the session as a
read. Only if the client asks for new analysis does this become a
linked consult.

## Department request

A marketing department asks: "Review this plan with the council: the
new offer launch sequence." The request carries the originating
department and task, the council result returns to that origin, and
follow-through still needs its own preview, approval, creation, and
execution authorization.
