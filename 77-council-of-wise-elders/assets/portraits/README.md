# Portraits: none produced

No seat portraits exist yet, and none are scaffolded here: a
placeholder portrait would inevitably be mistaken for the real person,
which this skill's label discipline forbids.

When portraits are produced by their owning unit, each one is entered
in ../portrait-manifest.json before it ships, with provenance, rights
status, content hash, dimensions, and alt text. The manifest is the
gate; this directory holds files only after their entries exist.
