# Council Runtime: NOT YET BUILT

This directory is the scaffold for the Council of Wise Elders
deliberation runtime. The runtime is owned by the core runtime unit
(CWE-004) and is **not yet built**. Nothing in this directory executes
a council session, and nothing here may be presented as a working
runtime.

What exists at this stage, honestly:

- `package.json`: a proposed internal package identity
  (`@blackceo/wise-elders-core`, private, version `0.0.0-scaffold`). It
  asserts nothing about npm; the package is not published anywhere.
- `package-lock.json`: generated by npm from the scaffold
  package.json. The runtime has zero dependencies at this stage.
- `tsconfig.json`: strict TypeScript scaffold settings for the future
  source tree.
- `src/`: empty of modules. The module layout (contracts, protocol,
  scoring, sources, context, providers, persistence, queue, budgets,
  reports, cli) is created by the runtime unit with real code; this
  scaffold ships no fake modules.
- `tests/`: empty of tests. Runtime tests arrive with the runtime.

`dist/` is a generated directory. It is intentionally absent and is
never hand-patched when it exists.

Until the runtime lands, the skill's front door reports the council as
not ready (FEATURE_NOT_READY) and spends zero provider requests. See
../references/install-matrix.md.
