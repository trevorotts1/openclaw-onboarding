Council of Wise Elders

Pages this standalone slice does not package

These journeys exist in the Command Center council UI. They are thin clients over authenticated, database-backed council APIs, so shipping them here would mean shipping a blank or a fake. Each blocker is named exactly.

RouteExact blocking dependency
/council (home session list) GET /api/council/sessions and GET /api/council/capabilities. Requires a verified tenant identity (resolveTenantContext) plus the Command Center database via src/lib/council/store.ts.
/council/<sessionId> GET /api/council/sessions/<id>, /verdict, /events?snapshot=1 and a live EventSource stream. Requires a real persisted session, the durable event journal/outbox, and a verified tenant.
/council/advisors as served by Command Center GET /api/council/advisors requires a verified tenant. A static roster built from the skill's own advisor packs is shipped instead at advisors.html.
/council/history GET /api/council/capabilities, /sessions, two /sessions/<id> reads and two /verdict reads. Requires real sessions and the Command Center database.
/council/new (guided intake) getModels() (GET /api/council/models) and createSession() (POST /api/council/sessions). Requires provider route discovery, a verified tenant, and a durable write.
/council/settings GET /api/council/settings. The endpoint is typed FEATURE_NOT_READY in Command Center and still requires the authenticated council API.
Why the whole UI cannot be a static export. Every page above is a client over the Command Center council API. That API resolves a verified tenant through src/lib/auth/tenant-context.ts and reads the Command Center database through src/lib/council/store.ts. A request from the council.zerohumanworkforce.com origin without a Command Center session or a verified Cloudflare Access JWT is refused by src/middleware.ts with HTTP 403 tenant_access_required before any council page renders.

This is an explicit not-packaged record, not a working substitute. The fixture-driven chamber and the static advisor roster are the only surfaces this slice ships.
