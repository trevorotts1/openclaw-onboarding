# Schemas: generated artifacts, never hand-written

This directory holds the council's generated JSON Schemas. Hand-writing
schemas here would fork the contracts, so every file in this directory is
generated from a canonical definition source and verified by a drift test.

## Current contents

- `json-schemas.json`: the JSON Schema artifact for the canonical
  contracts, generated by CWE-003 (coordinator decision D-006) from
  `runtime/src/contracts/schemas.ts` via `runtime/src/contracts/generate.ts`.
  It carries 26 contract schemas (session, brief, cards, verdict, run
  preview/grant, events, settings, receipts, diagnostic retention policy,
  endpoint contract, and the rest of the Section 11.6 inventory).
  Regenerate it with the command in `runtime/src/contracts/README.md`;
  the contracts test suite fails if this file drifts from the definitions.

Later units may add further generated schema artifacts here through the
normal package build; they are listed in manifest.json and verified by
scripts/verify-bundles.mjs like every other file in the tree.
