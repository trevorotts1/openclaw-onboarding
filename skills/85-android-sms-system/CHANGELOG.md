# Changelog - android-sms-system

All notable changes to this skill wrapper are documented here.

---

## [v1.0.0] - November 6, 2026

### Added
- Initial release of the Android SMS System skill (display name: Android SMS System).
- Built from the complete myCRMSIM offline support documentation set: 156 articles, 36 category pages, 660 images, and 788 MB of supporting assets.
- Channel coverage: Android SMS, iMessage, WhatsApp, RCS, and voice calling.
- Integration coverage: HighLevel, HubSpot, Zapier, Make, Salesforce, and Zoho.
- Automation guidance for workflows and AI agents, plus dashboard operations, snapshot workflows, and troubleshooting.
- Packaging follows the GHL skill layout: SKILL.md, INSTRUCTIONS.md, INSTALL.md, EXAMPLES.md, CORE_UPDATES.md, QC.md, qc script, PREREQS.json, CHANGELOG.md, skill-version.txt, and the `.skill` zip bundle.
- CORE_UPDATES uses one-to-two-sentence pointers only (WHAT, absolute WHERE, trigger WHEN) and deliberately adds no learning or installation receipts to MEMORY.md.
